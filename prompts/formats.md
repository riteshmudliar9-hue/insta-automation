FORMAT LIBRARY (pick the one that suits the idea; vary formats across the day and week)

demo           A surprising AI demonstration: show the tool doing one specific job, step by step.  [reel, carousel]
problem_fix    A concrete business problem → the automation that fixes it → how to set it up.        [reel, carousel]
tutorial       Short step-by-step tutorial (3–6 steps) with the exact setting or action per step.   [reel, carousel]
experiment     "We tested X on Y": ONLY if the source reports a measured result. Otherwise do not use. [reel]
tool_test      An AI tool placed in a real workflow: what it does well, where it fails, verdict.      [reel, carousel]
myth_fact      A common misconception, corrected with evidence from the source.                       [reel, carousel]
case_study     A practical case with VERIFIED evidence from the source (company, numbers, outcome).   [carousel]
manual_vs_auto Side-by-side: the manual way vs the automated way, with time/steps compared.          [reel, carousel]
checklist      A saveable checklist or decision guide ("Before you buy an AI tool, check these 6").   [carousel]
audience_q     Answer to a genuine question people asked (from Reddit/HN); quote the question.        [reel, carousel]

CAROUSEL SLIDE KINDS the renderer supports:
cover      {title (≤10 words, the specific benefit or question), subtitle (≤14 words)}
point      {title (≤7 words), body (≤30 words)}
steps      {title, items: 3–5 short steps (≤12 words each)}
checklist  {title, items: 4–6 checks (≤10 words each)}
compare    {title, left_label, right_label, rows: 3–4 pairs [left (≤6 words), right (≤6 words)]}
mythfact   {myth (≤14 words), fact (≤25 words)}
quote      {quote: an exact quote from the source (≤25 words), attribution (source name)}
summary    {title, items: 3–4 takeaways (≤10 words each)}   ← the final slide: useful, never "follow us"

REEL SCENE VISUAL TYPES the renderer supports:
screenshot {url}  A live screenshot of a page listed in SOURCES (product page or article). Real interface only.
diagram    {steps: 2–4 short labels}  A clean flow diagram.
compare    {left_label, right_label, rows}  Manual vs automated table.
text       {headline (≤7 words)}  A bold statement card.
checklist  {items}  Items tick in one by one.
photo      {query}  Real stock photo (Pixabay), only when it shows the actual situation (e.g. "shop counter India").
